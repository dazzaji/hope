# Long-Horizon Agent Work

Write your goal and success criteria (ie how would you know if the goal is achieved) in the goal.md file.

Let your agent help you write up how agents should achieve the goal in the sprint.md file (you can name this "project_plan.md" or whatever makes sense to you).  Depending on the goal you may want or need to structure the sprint in phases separated by "gates" which have their own success criteria and tests.  Some gates may further require you (the human principal) to personally approve and authorize continuation to the next phase.

As a starting point, you can use all or parts of the [Interlateral Agents](https://github.com/dazzaji/interlateral_agents/) open source project for tooling and design patterns to enable long-horizon agent work.

Have your agent read the [Overnight Cookbook](https://github.com/dazzaji/interlateral_agents/blob/main/docs/overnight-cookbook.md) for example approaches, tips, and traps to avoid when attempting long-running multi-agent projects.  If you use multiple agents from diverse providers (eg Codex from OpenAI and Claude Code from Anthropic and Grok Build from SpaceXAI and Gemini from Google, etc) you may also want to use the LIVE_COMMS mesh network for the agents to communicate with each other and the SKILLS files for the agents to collaborate in various ways with each other.
